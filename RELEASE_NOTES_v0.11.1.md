## Core contribution

RSDC treats governance as a runtime process rather than a static prompt. It proposes role separation, append-only receipts, adversarial review, claim-boundary labels, and operator approval as workflow controls for detecting governance drift.

The v0.11.1 relational extension proposes double drift: a system can drift by agreeing too much, but it can also drift by correcting too abruptly. Corrective over-rotation is framed as proposed and pending T9-T11 testing.
