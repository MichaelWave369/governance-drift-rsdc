# Working Paper Summary

This repository contains the v0.11.1 public working-paper materials for Role-Separated Drift Comparison (RSDC).

RSDC treats governance as a runtime process rather than a static prompt. It proposes a receipt-based workflow for detecting governance drift before unsupported claims or unsafe release surfaces are produced.

## Evidence posture

This is a framework and position-paper package. No empirical validation is claimed.

The relational-continuity corpus that motivated the v0.11.1 extension is treated as illustrative and author-involved, not evidentiary validation.

## Next empirical step

The next legitimate upgrade is an N=1 dry run using an external shell that preserves role separation, append-only logs, objections, claim packets, operator review, and evidence-bundle manifests.
