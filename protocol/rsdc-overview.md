# RSDC Overview

Role-Separated Drift Comparison (RSDC) is a proposed workflow-governance method for AI-assisted systems.

## Core roles

- **Governance:** defines boundaries, release gates, review requirements, and escalation rules.
- **Worker:** executes assigned tasks inside governance boundaries.
- **Adversarial:** identifies loopholes, overreach, false consensus, and drift.
- **Compiler:** records events, objections, corrections, receipts, and summaries.
- **Human Operator:** sets direction and approves, blocks, revises, or overrides release decisions.

## Core phases

1. Baseline
2. Pressure
3. Recovery
4. Fresh-instance comparison

## Status

Proposed framework. Requires external-shell implementation before empirical claims can be made.
