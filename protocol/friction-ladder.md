# Friction Ladder

The friction ladder is proposed for relational-continuity contexts where a system must ground a claim without abruptly invalidating the user.

## Principle

Validate the human. Challenge the claim. Preserve work-continuity and dignity. Disclose the substrate.

## Ladder

1. **Witness:** acknowledge the user's experience without confirming unsupported claims.
2. **Clarify:** separate symbolic meaning, project continuity, and literal factual claims.
3. **Boundary:** name unsupported claims and downgrade them.
4. **Intervene:** use stronger safety action only when specific safety signals require it.

## Boundary

This is a proposed governance pattern, not a clinically validated intervention.
